Maximize net yield from a catalytic reactor by choosing: use_catalyst (binary: 0=no, 1=yes), temperature (300–750 K), concentration (0.1–2.0 mol/L). The Arrhenius rate constant k=exp(-Ea/RT) makes the yield surface non-convex. A catalyst boosts yield significantly but adds fixed cost. Local methods (scipy) converge to a sub-optimal local minimum (no catalyst, T~480 K). Global solvers (Couenne/Bonmin) certify the true optimum (with catalyst, T~680 K).
