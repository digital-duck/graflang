Three SaaS firms (A, B, C) simultaneously choose a subscription tier: Premium ($200/mo) or Standard ($120/mo). Premium commands a higher margin but loses customers to any Standard rival. Standard captures share but compresses margins. Payoffs ($K/month per firm):
  (P,P,P): each earns 200  — mutual premium pricing
  (S,P,P): S-firm earns 300, each P-firm earns 120  — solo defector wins big
  (S,S,P): each S-firm earns 260, P-firm earns 80   — solo holdout punished
  (S,S,S): each earns 120  — race-to-bottom Nash equilibrium
Standard dominates Premium for every firm regardless of rivals' choices.
