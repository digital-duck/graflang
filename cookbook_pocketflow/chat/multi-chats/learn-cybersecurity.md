# How to Learn Cybersecurity

## 1. Build the foundations
- **Networking:** TCP/IP, DNS, HTTP/HTTPS, firewalls. (Professor Messer's free Network+ videos are a good start.)
- **Operating systems:** Get comfortable with the Linux command line and with Windows internals and Active Directory.
- **Programming:** Python for scripting and automation. Add basic Bash and SQL. Learn some C or JavaScript later for exploit and web work.

## 2. Pick a direction
- **Offensive (red team, pentesting):** finding and exploiting weaknesses.
- **Defensive (blue team, SOC, incident response):** monitoring, detection, response.
- **Other areas:** application security, cloud security, GRC (governance, risk and compliance), malware analysis, forensics.

## 3. Practice hands-on
These are the fastest way to learn:
- **TryHackMe:** guided and beginner-friendly. Start with the "Pre Security" and "Jr Penetration Tester" paths.
- **Hack The Box / HTB Academy:** harder, more realistic.
- **OverTheWire (Bandit):** Linux and basic security wargames.
- **PortSwigger Web Security Academy:** free and the best resource for web vulnerabilities.
- **picoCTF and other CTFs:** good for competition-style practice.
- **Home lab:** Run VMs (VirtualBox or Proxmox) with Kali Linux, a vulnerable target such as Metasploitable or DVWA, and a SIEM like Wazuh or Security Onion.

## 4. Study and certify (optional)
- **Beginner:** CompTIA Security+ (the standard entry-level cert).
- **Intermediate:** CySA+, PNPT, eJPT, BTL1.
- **Advanced:** OSCP (offensive), CISSP (management).

Certs help with HR filters, but demonstrated skills matter more.

## 5. Learn continuously
- **News and blogs:** Krebs on Security, The Hacker News, Risky Business podcast.
- **Frameworks:** MITRE ATT&CK, the OWASP Top 10, the NIST Cybersecurity Framework.
- **Community:** Reddit's r/netsec and r/cybersecurity, Discord servers, local meetups (BSides, DEF CON groups).

## 6. Build a portfolio
- Write up CTF and lab solutions on a blog or GitHub.
- Try bug bounties (HackerOne, Bugcrowd) once you have web basics.
- Contribute to open-source security tools.

## Suggested first 3 months
1. **Month 1:** Networking and Linux basics, plus TryHackMe Pre Security.
2. **Month 2:** Python, then the TryHackMe Jr Pentester or SOC Level 1 path.
3. **Month 3:** PortSwigger labs or HTB, start a home lab, and begin Security+ study.

**Important:** Only test systems you own or have explicit written permission to test. Use legal practice platforms.
