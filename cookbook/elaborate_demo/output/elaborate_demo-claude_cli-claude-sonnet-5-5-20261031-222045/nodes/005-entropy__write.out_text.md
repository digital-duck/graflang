Shannon entropy is a number that measures how surprising, or unpredictable, the outcomes of something are, using the probability of each possible result: a coin that always lands heads has zero entropy because you're never surprised, while a fair coin (50/50) is the most unpredictable two-outcome case. It works by giving each outcome a "surprise" score that grows as its probability shrinks (rare events are more surprising), then averaging those scores weighted by how often each outcome happens. The result is often measured in bits, which tells you the average number of yes/no questions you'd need to ask to pin down the outcome, so a fair coin has 1 bit, a fair six-sided die has about 2.6 bits, and more possible outcomes spread evenly means more entropy.
