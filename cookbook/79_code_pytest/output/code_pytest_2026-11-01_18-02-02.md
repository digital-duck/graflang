## Generated Code

```python
def merge_sorted(a, b):
    result = []
    i = 0
    j = 0
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            result.append(a[i])
            i += 1
        else:
            result.append(b[j])
            j += 1
    while i < len(a):
        result.append(a[i])
        i += 1
    while j < len(b):
        result.append(b[j])
        j += 1
    return result
```

## Explanation

The function uses the classic two-pointer merge: it keeps one position marker in each input list, compares the two current elements, appends the smaller one to the result, and advances only the marker whose element was taken. Because each element is appended exactly once and each marker only moves forward, the work is proportional to the combined length of the lists, which meets the O(n+m) requirement without any call to sorted() or list.sort(). Once one list runs out, the two trailing loops copy whatever remains of the other list, which is safe because that leftover is already in ascending order. Edge cases handled include empty inputs (one or both lists empty simply skip the main loop and the leftovers are copied or an empty list is returned), lists of different lengths, and duplicate values, where the use of "less than or equal" takes from the first list on ties and keeps the merge stable.
