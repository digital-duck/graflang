```python
def merge_sorted(a, b):
    result = []
    i = 0
    j = 0
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            result.append(a[i])
            i += 1
        else:
            result.append(b[j])
            j += 1
    while i < len(a):
        result.append(a[i])
        i += 1
    while j < len(b):
        result.append(b[j])
        j += 1
    return result
```

## Explanation

The function uses the classic two-pointer merge from merge sort: one index walks through each list, and at every step it compares the two current elements, copies the smaller into the result, and advances only that list's index. Once one list runs out, the two trailing loops append whatever remains of the other list, which is already sorted and therefore needs no further comparison. Each element is appended exactly once and no sorting function is used, so the running time is O(n+m).

Edge cases are handled naturally by the structure: an empty list on either side skips the main loop and the leftovers are copied straight over, two empty lists return an empty list, and lists of very different lengths are covered by the trailing loops. Duplicates are also handled, and using "less than or equal" when comparing takes from the first list on ties, which keeps the merge stable.
