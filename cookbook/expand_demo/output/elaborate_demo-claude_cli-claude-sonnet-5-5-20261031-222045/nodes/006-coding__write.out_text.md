Optimal coding is the art of writing messages in a code (like 0s and 1s) so that, on average, they come out as short as possible without losing any information. The trick is to give short codewords to common outcomes and long ones to rare outcomes, much like Morse code gives the frequent letter "E" a single dot. Shannon entropy sets the limit: no code can average fewer bits per outcome than the entropy, so a fair coin needs 1 bit per flip, while a lopsided coin that is usually heads can be squeezed into less.
